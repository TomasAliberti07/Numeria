IMPORTANTE DEBES PRENDER EL  BACKEND PRIMERO ANTES DE ARRANCAR FRONTEND
Una vez parado en backend si no estas en el pon el comando cd backend
comandos para arrancar backend:
1 venv\Scripts\activate.bat 
2 uvicorn app.main:app --reload

Una vez parado en el frontend si no estas en el pon el comando cd frontend
Comando para arrancar frontend: 
npm run dev

Ver la base de datos: 
python -m sqlite3 numeria.db
